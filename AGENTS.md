# Repository Instructions

## Git workflow

After completing any requested file modification in this repository:

1. Run `git add .`.
2. Create a commit with a concise Chinese message that accurately describes the change.
3. Run `git push` to push the commit to the current upstream branch.

Do not leave completed file modifications uncommitted or unpushed unless the user explicitly asks otherwise or the operation is blocked. If committing or pushing fails, report the exact blocker to the user.
